# Logos

The IndaVillas mark, eight triangles, copied unchanged from the live site's header SVG. Each file is single-ink because an `<img>` cannot inherit colour:

- `indavillas-mark-teal.svg`: ink `teal` light value (#13564F). Use on `limewash`, `paper` and `stone`.
- `indavillas-mark-brass.svg`: ink #C9A15A. Use on `teal-deep` and in the dark theme.
- `indavillas-mark-limewash.svg`: ink `limewash` (#F3F4F1). Use on photographs only where the area under it is dark.

Clear space around the mark is at least half its width. Minimum width 20px. The wordmark is set in type (see Logo in the brand book); there is no outlined wordmark file yet.
